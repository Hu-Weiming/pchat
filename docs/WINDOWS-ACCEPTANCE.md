# Windows 0.1.0 操作验收

本机安装目录：`D:\Dev\apps\Pchat`。运行 `pchat-desktop.exe` 打开正式前端，无需启动开发服务器。关闭窗口会收进托盘；托盘菜单“退出 Pchat”才会停止后台。

## 填写连接与资料

1. 点击左下角“连接与资料设置”，选择 DeepSeek，输入自己的 API Key、模型 ID，以及该模型支持的上下文窗口和输出上限，点击“安全保存连接”。保存成功只表示本地配置完成，首次真实回答才验证账户与模型可用性。
2. 切换到百度千帆，保存其 API Key。先在千帆控制台上传文档并等待索引完成，每个人物思想阶段使用独立知识库。
3. 输入知识库 ID，点击“读取资料清单”。核对人物阶段、作品名称、原典/研究类型和版本，再确认启用。Pchat 不上传文档；密钥需具备知识库检索、文档列表、切片列表及详情的只读权限。

未准备资料时人物列表为空，这是正式目录。密钥只在输入期间经过设置页，保存后清空；Rust Host 使用 Windows 当前用户 DPAPI 加密保存，不把密钥交给 Node、Harness 或数据库。加密凭证不能直接迁移给另一 Windows 用户使用。

## 检查主流程

- 新建讨论，选择 1–3 个人物、知识模式、模型和检索连接。提交一个问题，检查流式回答及“依据”视图。
- A 回答期间连续提交 B、C，检查排队顺序，尝试撤回尚未执行的问题。
- 点击停止，检查本轮未完成回答停止、已完成回答保留、后续队列暂停；明确恢复后继续。
- 退出并重开，检查历史与草稿保留。遇到“调用结果未知”时由用户选择重新生成；程序不会自动重复付费调用。
- 对照只展示本轮至少两个有效回答的原内容列，当前版本没有自动提取结论、前提或核心分歧。资料缺少稳定定位时只能概述，不能提供伪造逐字引文。

当前累计调用额度上限为 100 个内部单位，模型及检索详情调用均占额度；这不是人民币限额，也不会在重启时重置。真实费用以供应商账单为准。生产接入和内容质量验收仍需真实 Key、资料与用户核对，不以替身测试代替。

## 数据与安装

默认状态目录 `D:\Dev\state\pchat`，包括 SQLite、配置、加密凭证、知识库确认草稿、WebView 数据和运行临时文件。设置当前进程 `PCHAT_DEV_ROOT` 可换用其下的 `state/pchat`。安装在 D 盘；本机使用 `/NS` 不创建快捷方式，保留原 C 盘 P0 安装。

重现安装版接线检查（使用新建的隔离数据目录，不发出供应商请求）：

```powershell
. D:\Dev\pchat-env.ps1
./scripts/verify-installed.ps1 -Executable 'D:\Dev\apps\Pchat\pchat-desktop.exe' -OutputRoot 'D:\Dev\temp\pchat'
```

脚本要求真实安装页成功读取人物、会话并订阅事件，随后退出并确认捆绑 Runtime 已清理。不能只依赖 GUI 进程的退出码判定通过。

## 后续常见修改的边界

| 修改 | 主要位置 |
| --- | --- |
| 新模型、模型请求格式、提示策略 | `packages/providers` 的 ModelPort adapter；Host 增加明确的网络白名单 |
| 本地开发机检索或其他在线知识库 | 新 RAGPort adapter；不改 Harness 轮次与队列 |
| 人物、思想阶段、资料版本 | 已确认资料包与配置数据；不执行人物代码 |
| 上下文窗口、计数和压缩策略 | Harness context policy/counter 与 Windows composition 配置 |
| 页面和操作流程 | `apps/desktop/src/ui` 与 PchatClient；不直接读写 SQLite |

暂不建设通用插件平台。签名分发、真实供应商取消/费用效果、哲学资料质量和长历史性能是后续验收项。
