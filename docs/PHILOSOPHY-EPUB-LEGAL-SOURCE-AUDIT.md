## 必须先知道的版权边界

1. “原著已经进入公共领域”不等于“现代中文译本也可以免费复制”。译者对译文拥有独立版权。
2. Project Gutenberg 对作品的判断以美国法律为主，并要求美国以外的使用者自行确认所在地法律。
3. 中国著作权的一般保护期为作者终生及死亡后五十年，合作作品、匿名作品等有另外规则。参见[《中华人民共和国著作权法》第二十三条](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html)。
4. 本表不是法律意见；实际下载时仍应把来源页、许可说明、下载日期、语言、译者和文件 SHA-256 一起保存。

## 下载执行建议

建议下载程序只自动处理状态为 **可下载** 的链接，并为每个文件同时生成元数据记录：

```json
{
  "author": "Immanuel Kant",
  "work": "Critique of Pure Reason",
  "language": "en",
  "translator": "J. M. D. Meiklejohn",
  "sourcePage": "https://www.gutenberg.org/ebooks/4280",
  "downloadUrl": "https://www.gutenberg.org/ebooks/4280.epub3.images",
  "downloadedAt": "2026-09-11T00:00:00Z",
  "rightsNote": "Project Gutenberg: public domain in the USA",
  "sha256": "下载后计算"
}
```

执行规则：

1. EPUB 和元数据 JSON 成对保存；文件名只用 ASCII，避免后续工具对中文路径支持不一致。
2. 下载后验证 HTTP 状态、MIME 类型、文件大小、EPUB ZIP 结构和 SHA-256。
3. 同一作品的不同语言、译本必须是不同文件，绝不合并来源信息。
4. Internet Archive 只下载明确无借阅限制的公版文件；出现 `Borrow`、DRM 或受限访问时立即跳过。
5. “不可免费下载”的作品只记录出版社页面，不下载正文，也不尝试绕过 DRM。
6. 公开领域原文可以进入知识库；如将来购买正版个人电子书，是否允许上传第三方云知识库还要核对购买条款和云服务的数据使用条款。
